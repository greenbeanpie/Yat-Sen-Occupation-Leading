严重程度按可达路径和影响校正：P0 为无需额外前提即可接管真实账号；P1 为确证越权、敏感数据生命周期或实际服务滥用风险；P2 为有条件的安全/可靠性问题；P3 为维护建议。隐私、年龄、跨境等产品和法律判断不以技术审查代替，标记“待决策”，不假称自动满足法规。

当前站点仍保留演示学生和 mock 模型。公开演示管理员没有与生产公共岗位分区，因此本次禁止其管理接口及公共岗位管理权限；正常公开岗位浏览与本人演示分区功能保留。真实管理员只能由既有可信流程赋权，本次没有修改实际账号角色或签发凭据。

## 独立审查与验证范围

修复前独立只读审查确认入口、异步处理器、sync共同写入边界，并纠正 P0-9。修复后另一独立只读审查发现三项存活缺陷：上传与 DELETE/reset 竞态、提醒发送前异常漏推、Workflow耗尽后 running 永久占槽。三项均已补修；前两项及 running 清理增加本地故障/竞态回归。上传竞态用实际路由、真实D1/R2及Node到workerd流适配器注入，普通上传仍经真实workerd HTTP验证，不把该注入测试描述成全程Workflow端到端测试。

无生产迁移、发布、推送、实际秘密/邀请码签发。本地测试初始化失败和隔离目录dry-run写入拒绝均作为失败记录，只有成功执行后的结果才计通过。最终命令与结果见 [security-fix-runbook.md](security-fix-runbook.md)。
